# v2 점검 및 수정 기록

## 변경 사항

- 원래의 오프화이트/차콜/연두색 팔레트와 큰 모토, 여백 중심 구성을 유지했습니다.
- 단일 HTML 안의 스타일·스크립트·더미 데이터·SVG를 역할별 파일로 분리했습니다.
- 작업 3개를 12개로 늘렸습니다. 패션, 일러스트레이션, 디지털 콘텐츠 각각 4개입니다.
- 표지 12개와 상세 이미지 12개를 로컬 SVG로 구성했습니다. 메인 이미지와 이미지 오류 시 대체 이미지도 포함됩니다.
- 작업 개수와 순번을 데이터에서 계산하며, 필터 적용 후에도 카드 배치가 다시 정렬됩니다.
- 상세창에 표지/상세 이미지, 역할, 작업 과정, 이전/다음 이동을 추가했습니다.
- native dialog로 키보드 포커스 제한과 Escape 닫기를 구현했고, 닫은 뒤 원래 작업 링크로 초점을 돌립니다.
- 작업 카드는 정식 링크여서 키보드 Enter, 새 탭 열기, 직접 링크 방문이 가능합니다.
- 한/영 문구를 공통 데이터로 관리하며, 선택 언어를 저장합니다. 저장 기능이 차단돼도 동작합니다.
- 잘못된 카테고리·프로젝트 링크를 정상 목록으로 복구합니다. 선택 카테고리와 직접 링크 프로젝트가 다르면 해당 프로젝트가 보이도록 조정합니다.
- 클릭 이벤트를 한 번만 등록해 다시 그릴 때 중복 실행되지 않게 했습니다.
- 확인되지 않은 수상·전시·도구 숙련도를 실제 이력처럼 표시하지 않았습니다.

## 완료한 검사

### 자동 검사: 6개 통과

1. 데이터 유효성과 분야별 필터 및 순서
2. 잘못된 URL 상태 복구, 카테고리와 프로젝트 일치 처리
3. 중복 ID 및 번역 누락 감지
4. 화면 문구와 프로필의 국문/영문 존재 여부
5. 24개 프로젝트 이미지 파일 경로, 설명, 더미 표시
6. 필터 변경 후 직접 링크에 이전 카테고리가 남지 않는지 확인

### 앱 브라우저에서 확인

- 전체 12개, 분야별 4개 및 표시 개수 일치
- 상세창의 2개 이미지, 국문/영문 내용 전환
- 이전/다음 이동, 마지막 작업에서 다음 버튼 비활성화
- 키보드로 작업 열기, Escape 닫기, 초점 복귀, 배경 스크롤 잠금 해제
- 상세창 안에서 키보드 이동이 유지되는지 확인
- 모바일 메뉴 펼치기 및 메뉴 선택 후 접힘
- 상세 링크 새로고침 후 해당 작업 다시 열림
- 잘못된 프로젝트 URL에서 정상 12개 목록 표시
- 국문/영문 모두 CSS 화면 너비 320, 375, 768, 1024, 1440px에서 문서 가로 넘침 없음
- 관찰된 브라우저 콘솔 오류 없음
- 로드된 이미지에서 깨진 이미지 없음

## 검토 범위와 다음 작업

앱에 포함된 브라우저에서 검사했습니다. 별도 Chrome 자동화 실행은 환경 제한으로 시작하지 못해 앱 브라우저로 확인했습니다. 실제 iPhone/Safari/Firefox 및 스크린리더의 전체 호환성 검사는 수행하지 않았습니다.

현재 버전은 로컬 검토용입니다. 실제 이미지·프로젝트 설명·연락처·이력 입력과 최종 배포는 다음 작업에 해당합니다. 향후 코드 변경 시 이 검사를 다시 진행해야 하며, 현재 검사 통과가 이후 모든 수정의 무결성을 보장하지는 않습니다.

README에 실행 방법과 수정 위치를 정리했습니다. 원본 v1은 별도 백업 ZIP으로 보존했습니다.
